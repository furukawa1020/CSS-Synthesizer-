# Issue #190 — 範囲と間隔から対象点数を表示

最終方式ではdata-totalを型付きattr()で数として読み、範囲内の最終indexをL=floor((N−1)r)、間隔をsとしてfloor(L/s)+1を数える。r=1で最終indexが間隔に乗らないときだけ1を加える。結果をCSS counterの整数として出す。非対応時は対象数を隠す。

初期の子孫counter-incrementを後続要素で読む方式は、ブラウザで0表示になったため統合Issue #196で撤去した。最終方式は96/192/97点×範囲3種×間隔3種の27組合せで、算術counterとmaskで対象となる点の数を照合した。

対象数は不透明度・接線の微分ゼロ・領域外clip・重なりを差し引かず、実際のピクセル数や計算削減を示さない。

構文の参考は[CSS Values 5草案](https://drafts.csswg.org/css-values-5/)。構文対応を実動作保証とはせず、実ブラウザ観測を別に記録する。
