# 一列の操作と開閉の観測

2026-11-09 JST、クラウドChrome。実装者による確認。

- 1363×936 CSS px。描画は幅1152px、上133〜下582.27px。3つの選択欄と「数値を戻す」「細かな調整」を同じ操作列に配置した。位相0°と90°の選択、反復3・大きさ25%への変更、resetで2・90°・70%への復元でページの縦位置0を保持した。
- 位相0°で192点の中心基準 x+y の最大絶対値は0.00785 CSS px未満。90°では点の半径差0.01564px未満。
- 帯モードで180°へ変更して「細かな調整」を閉じても有効値180°を保持し、そのまま0°へ変更できた。帯モードでは描画の高さを200pxにし、操作時も見える位置に保つ。切替直後の1回の読み取りを確定値とせず、後続の観測で有効値と帯の位置を確認した。
- 直接選択の45°と、帯の180°を往復し、それぞれの値を保持した。
- 「使い方」の深いリンクから調整欄・説明欄・最初の操作説明が開いた。対象段落の上端は254.86px。
- 描画拡大と復帰で2・90°・70%、時計0を保持。拡大時の描画は8〜794px、復帰後は133〜582.27px。
- 幅390×高さ780のiframeはclientWidth/scrollWidthとも390px。幅320×高さ680ではとも305px。横はみ出しなし。3選択欄はそれぞれ一列に収まり、高さ44px。390幅の位相選択と矢印キーによる45°への変更、320幅の大きさ25%とEnterによるresetを確認。reset後の描画は上35〜下307pxで見える範囲にあった。
