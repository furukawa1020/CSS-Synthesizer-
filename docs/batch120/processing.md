# 座標加工の定義

2026-11-02。元モデルの正規化座標p=(x,y)に以下を順番に適用する。モデルのk/φ/A/tを加工しない。

1. 任意の(x,y)交換
2. 選択軸の絶対値
3. 選択された軸への投影（他方を0にする）
4. x/yゲイン0.5/1/2
5. x/y移動−0.25/0/+0.25
6. 任意の共通刻み0.1/0.25/0.5へのround(nearest)。同距離は+∞側
7. 任意のp/max(1,hypot(x,y))。原点の除数は1
8. 既存の左右/上下反転→回転→等方倍率

切り抜きと点のmaskは別で、対象点数は加工後の重複や領域外を差し引かない。絶対値や量子化では微分できない点が生じる。全加工で元モデルの接線は使わず、矢印選択時は丸点へ戻す。これは加工曲線の接線を実装したという主張ではない。

一次資料: [CSS Values 4](https://drafts.csswg.org/css-values-4/) のround/abs/sign/hypot。構文検出を実動作の保証にはしない。
