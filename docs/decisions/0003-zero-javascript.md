# ADR-0003：開発用も含めてJavaScriptを使用しない

日付：2026-10-27（日本時間）。根拠：ユーザーの「jsめっちゃ使ってるくない？ゼロでお願いします」。関連：Issue #7。ADR-0002のNode採用部分を置き換える。

## 決定

作品のHTML/CSSだけでなく、現在のリポジトリの生成・監査・テスト・ローカル配信・検証fixture・配布ツールからもJavaScriptを撤去する。JS/TSファイルとpackage.jsonを削除し、Python 3.11以上の標準ライブラリだけを使う。ブラウザへPythonを配信・実行するわけではない。

CSSによる座標・入力・時間の計算は変更しない。WebAssembly、スクリプトの難読化やインライン化、Canvas等でゼロという主張を補わない。配布は3 HTML / 2 CSSと説明・チェックサムだけにする。

CIもNodeのセットアップやNode製checkout actionを使用せず、公開リポジトリをGitで取得してPythonで検証する。開発環境自体やブラウザ、GitHubサービスの内部実装までJavaScript不使用と主張するものではない。

## 検証

- `tests/test_tools.py`が現在のソースにJS/TSファイル、Node manifestがないことを検査する。
- HTMLのscript、イベント属性、能動的埋め込み、別の描画経路を拒否する静的ガードをPythonへ移植する。
- ビルド出力の再生成一致、配布ZIPの再現一致、余分なQAファイルの混入拒否を確認する。
- 読み取り用のブラウザ観測データはJSONとして保存し、Pythonのmath.sinで独立に照合する。ブラウザ操作サービスの内部コードを作品の依存にしない。

## 履歴

PR #4では、ブラウザ内だけをHTML/CSSに限定し、開発用にNodeを採用していた。この判断は指定に合わなかったため撤去する。過去のコミット・検証記録は履歴として残す。現在のツリーと配布物のゼロを検査し、過去の履歴もゼロであったとは主張しない。
