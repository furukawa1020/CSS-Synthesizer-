# ADR 0001：旧試作を継承せず、要件定義から開始する

日付：2026-10-26

状態：やり直しはユーザー指示による確定。個々の製品・UI案は未確定。

## 背景

最初の試作は要件定義より先に外観と実装を決定した。ユーザーから「雑」「UIがAIっぽい」と指摘され、新規リポジトリからの開始を求められた。

## 決定

- 新しいGit履歴で開始する。
- 旧試作のソース、スタイル、ブランド、配信設定をコピーしない。
- 実装より先の初期コミット群に目的・数理モデル・入力・状態・構成案・受け入れ条件を含める。
- 製品名、見た目、点数、4モデル、全ブラウザ対応を決定済みとして引き継がない。
- 観測していない性能・実機操作・ユーザーテストを結果として記載しない。

## 理由

配色や装飾だけ変えても、入力の意味や状態が定義されていない問題は解消しない。まずレビューできる仕様を作り、技術的に不確かな点を小さく検証してから本実装へ進む。

## 影響

この初期コミット群に動くアプリはない。これは実装を放棄した状態ではなく、ユーザーが求めた順序で進めるための区切りである。
