## キーボードでの巡回・選択

解説を閉じた状態のTab順序は次のとおり。

1. 「調整へ進む」スキップリンク。
2. ヘッダーの「使い方と仕組み」リンク。
3. 選択中の形のラジオボタン。
4. 選択中の時間のラジオボタン。
5. 反復の減少矢印、増加矢印、スクロール帯。
6. 位相の減少矢印、増加矢印、スクロール帯。
7. 振幅の減少矢印、増加矢印、スクロール帯。
8. 解説のsummary。
9. フッターのソースコードリンク。

続くTabでページ内のフォーカス対象を抜け、ページ内に閉じ込められなかった。ラジオグループ内は選択中の項目をTabで受け、矢印キーで選択を変える通常の挙動だった。

形ではArrowRightでリサージュから波形へ変更できた。時間では「端末に従う」からArrowLeftで「停止」、「停止」からArrowLeftで「再生」、「再生」からArrowRightで「停止」へ変更できた。全ブラウザや全キー組み合わせの保証ではなく、今回操作した遷移の記録である。

[Tab順序の観測JSON](../../qa/evidence/issue-3-tab-order.json)と[操作画面](../../qa/evidence/issue-3-keyboard.jpg)を保存した。

## 3入力の両端へ到達

帯へフォーカスした後、Shift+Tabで生成矢印へ移り、Enterで繰り返し作動させた。ブラウザのスムーズスクロールが落ち着いてから、位置・有効値・表示値を確認した。

| 入力 | 下端のscrollLeft / 有効値 / 表示 | 上端のscrollLeft / 有効値 / 表示 |
| --- | --- | --- |
| 反復 | 0 px / 1 / 1.00 | 2800 px / 8 / 8.00 |
| 位相 | 0 px / 0 / 0° | 1440 px / 360 / 360° |
| 振幅 | 0 px / 0.25 / 25% | 1500 px / 1 / 100% |

各端点では、さらに外側へ送る生成矢印がdisabledとなった。生成矢印は一定の数値刻みではなく、ブラウザのページ送りである。

左右キーによる帯のスクロールも確認した。振幅のArrowLeftでscrollLeftと生の値が減少し、スクロール完了後の表示は98%となった。位相0°の帯へArrowRightを送った直後の読み取りは0°だった。一回のキー操作を一定数値ずつ増える操作として扱わない。Home / Endでの到達は今回の結果に含めない。

帯のフォーカス表示は`3px solid rgb(146, 61, 37)`だった。

## 停止・再開と解説

時間停止後の時計値`0.0831213`は、上記の端点操作と解説の開閉を通じて変化しなかった。再生後は`2.7952`へ進み、再び停止して値が落ち着いた時点で`2.98273`となり、その後の読み取りでも同値を維持した。停止したまま入力を編集でき、再開で時計が進むことを確認した。

解説は`<details>`であり、dialogやinertによるモーダル表示ではない。summaryのSpaceで開閉できた。展開中のTab移動では、96点、384点、描画ソース、数式の仕様、検証状況、フッターのリンクへ進めた。他のUIを非操作にしたり、閉じた際に別の操作箇所へフォーカスを戻したりする仕様ではない。以前の状態表にあったモーダル相当の記述を、現在の実装に合わせて修正した。

## 静的な0／2π端点

時間を固定する既存のCSS fixtureで、開始側の時計`0`、終了側のシリアライズ値`6.28319`をブラウザから読み取った。反復3.00、位相90°、振幅80%に固定し、2モデルそれぞれについて全192点のDOM中心を採取してPythonの独立した数式と照合した。

| モデル | 開始側の最大誤差 | 終了側の最大誤差 | 開始・終了のDOM点間の最大差 |
| --- | --- | --- | --- |
| リサージュ | 0.00004785125907 CSS px | 0.00005103232837 CSS px | 0.0017048923 CSS px |
| 波形 | 0.00004730694136 CSS px | 0.00004516043141 CSS px | 0.0011901855 CSS px |

独立照合の許容差は既定の0.1 CSS px。観測した終了時計を2πへクランプせず、JSONの値をそのまま使用した。各JSONのパラメータ・描画領域・点座標から、次のコマンドで再照合できる。

```sh
python3 -m tools.coordinates qa/evidence/issue-3-loop-lissajous-start.json
python3 -m tools.coordinates qa/evidence/issue-3-loop-lissajous-end.json
python3 -m tools.coordinates qa/evidence/issue-3-loop-wave-start.json
python3 -m tools.coordinates qa/evidence/issue-3-loop-wave-end.json
```

証跡：[リサージュ開始](../../qa/evidence/issue-3-loop-lissajous-start.json)、[リサージュ終了](../../qa/evidence/issue-3-loop-lissajous-end.json)、[波形開始](../../qa/evidence/issue-3-loop-wave-start.json)、[波形終了](../../qa/evidence/issue-3-loop-wave-end.json)。

これは静的な端点の照合である。実際に24秒間再生した動画の切り替わり、フレームの連続性、フレーム落ちや操作遅延を評価した結果ではない。
