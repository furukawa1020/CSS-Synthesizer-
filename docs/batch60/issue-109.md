# Issue #109 — 接線方向の矢印

点の形に「接線の矢印」を追加する。点の並びuが進む方向であり、時間で動く速度ベクトルではない。CSSで解析的な微分に比例するベクトル(dx,dy)を計算し、atan2(-dy,dx)で画面の向きを決める。塗りの疑似要素だけを動かし、sampleの中心座標は保つ。反転・倍率・回転はplotの外側で共通に適用される。

## 特異点と判定

微分ベクトルのノルムが0.000001未満なら矢印の塗りを隠す。Lissajousの停止点などで未定義の方向を表示しない。Fermatのu=0では微分の大きさが発散するため、正の2sqrt(u)を掛けた比例ベクトルを使い、その片側極限で有限の方向を定める。Fermatでのノルム閾値はこの比例ベクトルに対する値。端点印は別の疑似要素なので、矢印を隠しても端点位置を示せる。

atan2()・hypot()を@supportsで検出し、未対応時は選択肢を隠して理由を表示する。復元された矢印選択が丸として誤表示されないよう塗りも隠す。長さは通常の点幅の3倍、高さは2倍。印刷と強制カラーでも既存の塗り色を使う。

## 独立検査

tools.tangentsはCSS変数のdx/dyを期待値に使わず、Pythonで解析的ベクトルを計算する。8モデル・3入力状態・4点で、別に書いた位置式の有限差分の角度と照合する。Fermat始点の片側極限、微分0での非表示、角度の±360°同値性、不正な観測も検査する。

観測JSONはmodel/k/phase_degrees/amplitude/clock_radians/countと、tangents配列(index/visible/angle_degrees)を持つ。angle_degreesは疑似要素のローカルrotateの度数で、plot変換後の画面角ではない。

```sh
python3 -m tools.tangents observation.json
```

Python tests・生成・静的監査を実行。8モデルの実ブラウザcomputed rotate、点中心、微分0、回転・反転、印刷・強制カラーは統合検証で観測する。
