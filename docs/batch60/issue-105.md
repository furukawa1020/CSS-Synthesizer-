# Issue #105 — 位相φのラジアン換算表示

度を既定に、位相φの出力を小数3桁のラジアンへ切り替える。round/modでミリラジアン単位に丸め、@counter-styleのpad:3で小数部をゼロ埋めする。入力と式は同じ1°刻みの有効値を使い、見かけの桁数を入力精度の増加と扱わない。帯と目盛りリンクの単位は度を保ち、換算中の説明を表示する。自動時計tとは別の値。

印刷用の位相出力も選択単位を使い、ラジアン換算と入力の刻みを注記する。生成・参照監査と既存の数理検査を確認した。実ブラウザでは0°→0.000、90°→1.571、180°→3.142、270°→4.712、360°→6.283 radの表示、値の保持、小画面と印刷CSS分岐を統合QAで確認する。読み上げ更新の保証はしない。
