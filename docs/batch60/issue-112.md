# Issue #112 — モデル別の入力と式

## 要件と変更

使い方の中に8モデルの個別detailsを生成する。描画で選んだモデルに関係なく、名前、反復k・位相φ・振幅Aの意味、MathMLの全式、モデル固有の注意を開いて読める。既存の現在モデルの式表示は維持する。MathMLと説明は同じモデル定義から生成し、現在モデルに連動するdata-model-copyは付けない。

境界条件や開曲線、固定減衰率の説明を残す。sqrt()/exp()が必要なモデルも説明と数式は隠さず、描画に必要な機能を文で示す。平面の区切り線と文字組みを用い、左右の色線・カード影・大きな角丸を追加しない。

## 検査と限界

8件のdetailsと各式のMathML行、全入力説明・注意、モデル選択からの独立、名称のHTML escapeをPythonで検査した。107 unittest、生成とHTML/CSS監査が成功した。ブラウザでのdetails開閉・小画面レイアウト・読み上げや数式操作は統合検証で分けて記録する。JavaScriptは使用しない。
