# Issue #106 — 軌跡の回転

0/45/90/180°を表示設定で選び、plotだけを回転する。数学の座標と合わせて反時計回りを正とし、反転→回転の順。参照軸と入力値は変えず、端が領域外へ出る可能性を説明する。

CSSのindividual rotateは負角で指定し、既存scaleによる反転の外側に作用する。独立座標検査に任意の有限数rotation_degrees（省略時0）を追加。既知点を90°回転した結果と、反転と回転が可換でないケース、不正値を検査した。

Python tests・生成・静的監査を実行。実ブラウザでの45°、反転併用、印刷、小画面の観測は統合検証で行う。
