# Issue #111 — 新3モデルの停止プリセット

## 要件と変更

フェルマー渦巻き4/0°/90%、減衰波4/90°/90%、定在波2/0°/85%を追加する。各ページを時計t=0で停止して開き、ラジオ、初期目盛り、有効値、式を同じ状態にする。フェルマーはr=A sqrt(u)、減衰波は固定のexp(−3u)、定在波は空間の節と時計の分離を示す。

レジストリは既存7件を保持し計10件。既存の生成・配布定義から新ページとギャラリーの10例・各96点を生成する。validate_presetsを直接呼ぶ場合の既定モデルIDも現行レジストリから呼び出し時に読み、以前の5モデル固定を廃止する。load_presets(source)は引き続きそのsourceのモデル定義を渡す。

## 検証と限界

全プリセットページの選択モデル・停止・3初期目盛り・raw初期値の一致、ギャラリーの対象と点数、アセット定義をPythonで検査。新3モデルをレジストリ全モデルのプリセットが覆うことも検査する。build・全unittest・静的監査を実施する。ブラウザでの初期scroll timeline値と座標の観測は統合QAで行う。プリセットは現在の操作状態の保存ではなく、ページ移動で値と時計の保持を保証しない。
