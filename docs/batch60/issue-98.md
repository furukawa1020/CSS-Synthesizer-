# Issue #98 — 比較するモデルを選ぶ

比較ページに8モデルのcheckboxを追加し、既定でリサージュと波形を表示する。複数選択・全解除・再表示はHTMLのchecked状態と:has()だけで扱う。全解除時にはモデルを選ぶ案内を表示する。:has()不足では操作対象を出さず、描画機能不足時の説明とモデル名を残す。

各図は同じk・φ・Aでも意味が異なるため、入力の意味とモデルの注意を記載する。sqrt/exp不足の選択肢は隠す。履歴等で選択状態が復元された場合でも、既存のcapabilityルールで描画を隠して理由を示す。

構造と既定選択・各モデル用CSS条件・生成監査をPythonで確認する。全図の時計・有効値同期、全解除と復帰、実機性能は統合のブラウザ観測で確認する。非表示で点のHTMLが削除されるものではない。
