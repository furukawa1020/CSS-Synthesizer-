# Issue #108 — 極座標の角度目盛り

極座標モードで0〜315°を45°刻みに表示する。右0°・上90°の数理座標を使う。角度は参照軸の位置であり、plotの回転・反転には追従しない。

polar-labelをaxes内に置き、直交目盛りと排他的に表示。図中説明オフ、補助線オフは既存visibilityを継承する。パレット、強制カラー、印刷は既存axis-labelの文字色を使う。通常は半径36cqmin、300px以下の高さでは22cqminとして見出し・脚注の領域から離す。参照用単位円そのものは44cqminのまま。

生成・静的監査を実行。実ブラウザの小画面、低い横長図、文字拡大、印刷分岐での重なりは統合検証で観測する。

統合検証で文字200%時の重なりを確認し、Issue #116で修正した。高さは文字サイズ相対の20emを使い、狭いfigureでは8方向を図外の凡例へ切り替える。図中説明オフ・補助線オフとの連動を維持し、8数値を省略して合格にはしない。最終観測はvalidation.md参照。
