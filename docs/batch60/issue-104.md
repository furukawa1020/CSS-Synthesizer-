# Issue #104 — 目盛りへの吸着

既定の連続スクロールを維持し、任意のcheckboxでscroll-snap-type:inline mandatoryとtickのscroll-snap-align:startを有効にする。反復は整数、位相は90°、振幅は5%の既存目盛りを使う。調整帯の機能検出と同じ条件で設定を表示し、切り替えで位置が移る可能性を説明する。

生成・静的監査を確認した。実ブラウザでの吸着値、切り替え後の有効値、既存fragment移動・スクロール・矢印との併用は統合QAへ記録する。吸着の選択を一定刻みの加減ボタンとして扱わず、非表示の入力帯だけを動く操作として表示しない。
