# Issue #101 — 反復の目盛りへ直接移動

反復帯の1〜8にnative fragment linkの移動先を付け、閉じられるdetailsに目盛りリンクを置いた。full scrollport幅のtick boxを移動先とし、IDの重複や不存在は既存監査で検査する。比較画面と共有する入力HTMLをfragment化した。

目盛りリンクはURLの#を更新するが、操作状態を保存する機能ではない。従来の連続スクロールと生成矢印は保持する。Pythonでは生成したリンク先・ラベルと目盛りの対応、接頭辞の不正入力拒否を検査した。実スクロール位置、時間・他入力保持、キーボードと狭幅の観測は統合ブラウザQAに記録する。構文やID監査だけを操作合格とはしない。
