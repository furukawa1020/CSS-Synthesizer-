# Issue #99 — 比較図ごとの点数を選ぶ

compare.htmlは各96点、compare-192.htmlは各192点で生成する。比較ページ上部のリンクは別ページへの移動で、現在のページをaria-currentで示す。値と時計を保存したり引き継ぐ操作とは案内しない。

COMPARISON_COUNTSとcomparison_filenameを生成と配布定義が共有し、監査・ZIP検査も同じ総sample数を使用する。8モデルをHTMLに含めるため総数は768/1536点。非表示を含む全点のHTMLが残ることと、実端末の性能が未評価であることを説明する。

両ページのsample数・リンク先・現在表示・一意の共有入力をPythonで検査し、生成と静的監査を行う。実際の移動と表示、ブラウザごとの状態復元、性能は統合観測へ残す。
