# 初回操作の観測

2026-11-05 JST。クラウドChromeのプレビューで操作。通常画面は1363×936 CSS px。初見の利用者テストではなく、実装者による操作確認である。

## 通した操作

1. 絵の「まる」を押す。preset-circle.htmlに移動し、k=2.00、位相90°、大きさ70%、時計0で停止した円を表示。
2. 開閉欄を探さずに0°を押す。位相0°、帯のscrollLeft=0となり線に変化。192点の中心について、中心基準のx+yの最大絶対値は0.00785 CSS px未満。
3. 90°を押して円へ戻す。点の半径の最大値と最小値の差は0.01564 CSS px未満。このケースで描画はviewport上のtop=65.83、bottom=346.63 CSS pxにあり、基準値と同時に見えた。
4. 「別の形を選ぶ」から開始例へ戻り、「はな」を開く。「動かす」で時計が進み、「とめる」でpausedへ切り替わった。停止後に位相を90°へ変更し、後続の観測でも時計2.40807を保持した。

## 小さい表示幅

幅390px・高さ920pxのiframeで、開始例と時間操作、スクロール後の基準値を確認。スクロールバーを除くclientWidth=375、document scrollWidth=375。0°へのクリックと90°へのEnter操作で位相と帯が追従し、絵が見える位置を保った。これは実機タッチの検証ではない。

frameLocatorのマウス操作では別リンクへ送られるケースがあり、AXで見えているリンクを直接操作して確認し直した。操作が反映されていない時点を合格にしていない。
