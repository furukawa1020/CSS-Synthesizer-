# トップで円を線にする

トップは停止した円から始め、同じページの位相目盛りを0°と90°へ移動する。円と線は初期状態のリサージュ、反復2、停止時計0での結果。一度時計を動かした後の停止は時計を0へ戻さない。見本を開くと別ページへ移動する。

要件 F-02 / F-03 / F-04 / F-06、D-01〜07。

- #539 入口を停止した円から始める
- #538 描画をトップの最初に置く
- #541 円と線を描画のすぐ下で切り替える
- #537 円と線が変わる条件を示す
- #540 円に戻すための反復2を選べるようにする
- #542 動かすと止めるを再生操作としてまとめる
- #546 自動再生の選択名を明確にする
- #543 描画面を製図用紙のように整理する
- #545 描画中の技術情報を外側へ移す
- #544 初回の調整列を描画の横に置く
- #547 狭い画面で最初の操作までを短くする
- #548 目盛りへの移動で描画が隠れないようにする
- #550 位相を最初に触る調整として並べる
- #551 各調整の説明を一行にまとめる
- #549 選んだ目盛りを強調する
- #553 別の模様を下の作品索引から開く
- #552 描画だけの表示から実験に戻れるようにする
- #554 案内文を画面の操作名と揃える
- #556 狭幅・キーボード・印刷時の導線を整える
- #555 初回の操作経路を回帰検証に追加する
