# Issue #26：左右・上下の表示反転

作成：2026-10-28（日本時間）。実装前の要件：表示設定の2つのチェックボックスで左右・上下を独立に反転する。数式の入力、時計、点の順序は変えず、原点を中心に描画点だけを反転する。図中の文字と補助線は反転させない。

plot全体のCSS `scale`を左右`−1 / +1`、上下`−1 / +1`で切り替える。初期状態はどちらも+1。独立座標検証器では、JSONの任意フィールド`mirror_x`・`mirror_y`を真偽値だけで受け付ける。省略時はfalseとし、正規化座標の符号を変えてから共通スケールと原点位置へ写像する。時計や数理モデルの値を反転係数で書き換えない。

検証：既知の波形3点について左右・上下・両方の組み合わせ、縦長のリサージュ1点、反転忘れの誤座標、数値や文字列など不正な反転フラグをPythonで検査。ビルド、静的監査、全テスト、`git diff --check`を確認。ブラウザでの実描画と全モデルの反転は統合後のQA対象。
