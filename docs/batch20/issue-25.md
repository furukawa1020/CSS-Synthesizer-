# Issue #25：描画だけの配色選択

作成：2026-10-28（日本時間）。実装前の要件：作品領域に温色・青白・紙面の3配色を用意する。初期の温色は既存の背景`#17201f`・点`#ffd2ab`・文字色を維持し、操作画面の配色と数式は変えない。点、背景、図中ラベル、補助線を組として定義する。

青白は背景`#101f2c`・点`#d6f4ff`、紙面は背景`#f5f2e9`・点`#26352c`。図中の名前・点数・脚注は、各背景に対して4.5:1以上を目標とする。補助線は図形を補う非テキストの参照線であり、点より弱くする。

色選択をradioのチェック状態でも伝える。強制カラー環境ではこれらの作者配色を適用せず、システム色の設定に従う。

検証：Python標準ライブラリでsRGB相対輝度から点・図中ラベル・脚注と背景のコントラストを算出し、全組が4.5:1以上。ビルド・静的監査・`git diff --check`。実ブラウザの外観は統合後のQA対象。
