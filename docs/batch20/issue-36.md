# Issue #36：現在の形を印刷する

要件：ブラウザの印刷機能から、形・モデル・反復・位相・振幅・時計の位相と式を紙面へ出す。JSの印刷処理や画像書き出しは追加しない。

印刷メディアでは時計だけを停止する。操作帯をdisplay:noneにするとscroll timelineが消えて入力が初期値へ戻り得るため、操作パネルのレイアウトとスクロール位置を画面外に保持し、印刷用の値を別に表示する。animation:noneで時計や入力の値をリセットしない。

印刷の配色は白黒とし、反転と点の太さは保持する。グラフは140mm角、点は背景印刷を省く場合にも境界線が残る。時計は約1ミリラジアンの表示精度。式は現在のモデルのMathMLを使う。印刷先・余白・背景処理は利用者のブラウザ設定にも依存する。実OSや紙への出力は未検証として記録する。
