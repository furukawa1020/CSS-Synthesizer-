# Issue #19：花弁モデル

`r=A sin(kθ+φ)`、`x=r cos(θ+t)`、`y=r sin(θ+t)`を採用する。kは一周の半径方向の反復であり、自動回転の速度ではない。位相は半径の振動のずれ、振幅は両軸の大きさ。整数kでは閉じ、非整数では開くことがある。半径の負値もそのまま描く。

共通のk=1.00〜8.00、位相0〜360°、振幅25〜100%、24秒周期、44cqminの等方写像を使う。cosはsin(角度+90deg)として既存の三角関数ゲート内で表現し、新しい未検出機能を増やさない。

Python独立照合で4方位の既知点、時間による90°回転、非整数の開いた端点、座標のずれの拒否を検査する。ブラウザ実測と実機・性能はこの検査と区別する。
