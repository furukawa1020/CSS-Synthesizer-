# Issue #22：表示設定のネイティブPopover

作成：2026-10-28（日本時間）。実装前の要件：主操作はモデル・時間・3本の調整帯のまま保ち、表示だけを変える補助設定は必要なときに開く。最初の設定は図中の説明の表示／非表示とし、座標・入力・時計を変えない。

`popover="auto"`と`popovertarget`で開閉する。通常のfieldsetとチェックボックスを使い、メニュー用のARIAや独自キーボード処理を追加しない。Popover非対応時は通常フローの設定欄として表示し、呼び出しボタンは隠す。対応時は外側クリックとEscapeによる解除をブラウザに任せる。

枠線1本とタイポグラフィで構成し、角丸・影・左色線の囲みは使わない。最大幅は画面幅から32pxを引いた長さ、高さは表示領域内に制限し、必要に応じて縦スクロールする。ボタンとラベルの高さは44px以上。

検証：Pythonビルド、HTML/CSS静的監査、`git diff --check`。ブラウザでの開閉・Escape・フォーカス復帰・小画面表示は統合後のQA対象。静的監査をネイティブ挙動の実測と扱わない。
