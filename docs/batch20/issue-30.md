# Issue #30：ネイティブMathML

モデル定義内の式から、変数を`mi`、数値を`mn`、演算子を`mo`に分けたMathMLを生成する。三角関数名は通常体と関数適用演算子で表す。手書きの別数式を増やさず、セミコロンで定義した補助式も独立した行として表示する。

`math`自体のdisplayはHTMLのMathML指定に任せ、モデル切り替えCSSは外側のラッパーだけに適用する。式が幅を超えるときは数式領域内で横スクロールでき、ページ全体を押し広げない。文字を画像化せず、選択・拡大できる状態を維持する。

生成したXMLの要素・式の行数・関数と数値の意味付け、不正な文字と括弧の拒否をPythonで検査する。これだけでスクリーンリーダーの読み上げが適切と断定せず、実機読み上げの未検証を残す。
