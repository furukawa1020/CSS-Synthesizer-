# Issue #17：ソース断片の合成

目的：20件の機能を独立したHTML断片とCSS拡張で保持し、ブラウザへ渡すHTMLと2CSSへビルド時に合成する。実行時の依存やJSは増やさない。

`@@FRAGMENT:name@@`は`src/fragments/name.html`だけを参照する。未定義、循環、不正な名前、シンボリックリンクを拒否する。CSS拡張はファイル名順で合成し、配布構成は変えない。

検証：Python unittest32件、ビルド、静的監査、diff検査に成功。独立レビューで断片ディレクトリのリンクと不正な残存トークンも拒否し、回帰検査を追加した。ブラウザ操作の追加はこのIssueにはない。後続の各機能の実測は別に記録する。
