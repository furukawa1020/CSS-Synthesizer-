# Issue #21：合成軌道モデル

`x=A(0.65 cos(θ+t)+0.35 cos(kθ+φ−t))`、`y=A(0.65 sin(θ+t)−0.35 sin(kθ+φ−t))`を採用する。θに対して主円と副円が逆向きに回る軌跡を合成する。時間tに対しては両項を合わせた形全体が回転する。

kは副円側の反復、位相は副円側の位相ずれ、振幅は両軸の大きさ。係数の和は1なので正規化座標は両軸とも±A以内。整数kでは閉じ、非整数では開く場合がある。共通の範囲、丸め、24秒周期、等方写像を維持する。

独立座標検査では固定係数による既知の四分点、kと位相の作用、時間回転、非整数の端点を確認する。CSSから取得した計算結果を期待値として再利用しない。実ブラウザ・性能の合格はこのテストだけでは主張しない。
