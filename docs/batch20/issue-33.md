# Issue #33：展開しない配布ZIP検査

実装前の範囲：Python標準ライブラリのCLIで、配布物の名前・通常ファイル性・重複・サイズ上限・内部SHA-256・HTML/CSS監査を検査する。ZIPを展開しない。許可するアプリファイルは`tools.package.ASSETS`を参照し、プリセット追加後もその定義に追従する。

`SHA256SUMS`は同梱アプリファイルの整合性検査であり、READMEやZIP全体の真正性を証明しない。任意の外部manifest指定時はZIP全体のSHA-256も照合するが、manifest自身の信頼性は別問題である。アーカイブ16MiB、各ファイル2MiB、総展開サイズ8MiBを上限として読み取り前に拒否する。

検証予定：正常配布、内容改変、重複、危険な名前、非通常ファイル、欠落、内部hashを更新したJS混入、外部manifest不一致、サイズ上限を検査する。ブラウザの機能・性能評価は含めない。

形式の境界：既存の再現可能な配布ZIPと同じ無圧縮（ZIP_STORED）だけを受け付け、圧縮方式を使った展開量の偽装を避ける。OSのsymlink等に加えDOS directory属性も拒否する。

検証結果：正常ZIP、外部manifest、改変・JS混入・重複・危険名・非通常ファイル・圧縮方式・サイズ上限・CLIの8テストを確認。内部hashを一緒に作り直してもJS混入は静的監査で拒否した。外部manifestを使わない検査はZIP全体やREADMEの改変検出を保証しない。
