# Issue #35：強制カラーでの描画と操作

作成：2026-10-28（日本時間）。実装前の要件：`forced-colors: active`では作者の描画配色を優先せず、Canvas・CanvasText・Highlight・ButtonFace・ButtonText・GrayTextを使う。点、図中の説明、入力境界、選択状態、無効状態、フォーカスを見分けられる状態にする。画面全体へ`forced-color-adjust: none`を設定しない。

強制カラーではグラデーションの補助線が失われるため、補助線は実borderの十字軸と半径44cqminの基準円へ簡略化する。直交・極座標のどちらを選んだ場合もこの参照線を使うことを、設定内の説明で伝える。「なし」は十字軸と円のすべてを隠す。点は参照線より上へ描き、文字と反転設定の意味は維持する。

表示の反転は点にだけ作用するため、縦軸のborderをstage側に設ける。横軸と円はaxes側に置き、すべての線はポインタ操作を遮らない。軸線の長さは短辺基準の88cqminで、縦横を同じ倍率に保つ。

検証：HTML/CSS生成、静的監査、`git diff --check`。既存の配色CSSが強制カラー時に適用されず、補助線なしの選択が新しい縦軸も隠すことをソース上で確認した。強制分岐のブラウザfixture、実OSの強制カラー設定、読み上げの実測は未実施であり、これらを合格扱いしない。
