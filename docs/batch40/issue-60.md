# Issue #60 — 始点と終点

表示設定の「軌跡の端点」で印を有効にすると、u=0に大きい円、u=1に小さい四角の輪郭を付ける。標準はオフ。印はsample::beforeに載せ、点本体の寸法や座標変換を変えない。重なる閉曲線でも二つのサイズを区別しやすくするが、同じ位置に重なること自体は説明に明記する。

色はcurrentColor、輪郭は実borderとし、既存の配色・強制カラー・印刷に従う。点を範囲外に隠す設定ではvisibilityを継承して印も隠れる。点形状の描画は別の::afterを使用するため独立する。

生成・HTML参照監査と82件のPythonテストが成功。端点の見え方、太さ・反転・形状・範囲との組み合わせのブラウザ観測は統合検証に記録する。
