# Issue #57 — フェルマー渦巻き

r=A√u、α=kθ+φ+t、x=r cosα、y=r sinαをCSSのsqrt()で計算する。kは巻き数、φとtは全体の回転。既存のr=Auとの違いをモデル説明に記載した。描画は引き続き短辺の44%を1とする等倍率。

sqrt()構文が非対応なら選択肢を隠し理由を表示する。履歴等で選択済みでも誤った旧モデルを描かず点を隠す。MathMLは平方根をmsqrtで表す。

独立数式の既知の中心・四分点・終点と、誤差注入による不合格をPythonで検査する。実ブラウザの座標照合と非対応ブラウザ実機は統合時の検証対象で、この資料だけで合格としない。
