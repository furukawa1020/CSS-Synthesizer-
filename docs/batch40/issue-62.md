# Issue #62 — 点の形を選ぶ

## 要件

点を丸・四角・菱形で描き分け、点の中心を変えない。既定は丸。太さ・描画順の色・反転・端点の印と併用する。

## 実装

点の位置と寸法を持つ.sampleはそのままに、::afterに塗りを置く。菱形は塗りだけを45度回転する。位置用transformを持つ.sample自体を回すと座標まで回るため、分離する。端点用::beforeは空ける。強制カラーではCanvasText、印刷では黒の塗りとborderを使う。菱形の見た目の対角線は指定された点の太さの√2倍となる。

## 検証

Pythonビルド・生成監査を実行。座標transformと幅高さの宣言は維持した。ブラウザでの全点の中心照合と表示の組み合わせは統合検証へ残す。
