# Issue #63 — 点の先頭だけを表示する

## 要件

全体・先頭50%・先頭25%を静的に選べる。時間や計算する点数は変えない。範囲外の端点の印も表示しない。

## 実装

u≤選んだ範囲の点だけopacityを1、それ以外を0にする。round(down,clamp(0,1+limit−u,1),1)なので境界のuも含む。CSSの数値からvisibilityキーワードを生成する方法は使わず、opacityで点の箱と座標を維持する。端点擬似要素も同じ親のopacityで隠れる。全点の計算は継続するため、性能最適化とは表示しない。

96/192/384点ではu=i/(N−1)のため25%表示は24/48/96点、50%は48/96/192点となる。基準となるuの位置に点がない場合は直前の点まで表示する。

## 検証

Pythonビルド・生成監査を実行。数式による分岐を0、境界、1で確認した。実ブラウザの描画数と端点印の組み合わせは統合検証で観測する。
