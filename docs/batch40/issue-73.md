# Issue #73 — 開発ソースのJSゼロをCLIとCIで検査する

`python3 -m tools.source_audit`がルートのファイルと`src/`・`tools/`・`tests/`・`qa/`・`.github/`を検査し、JS/TS関連拡張子、WASM、Node等の依存マニフェスト、`node_modules`を拒否する。対象内のシンボリックリンクは追跡せず拒否する。CIではHTML生成前に実行する。

対象は現在の実装ファイル。Git履歴、build/dist/tmpの生成物、文書、qa/localの手元キャプチャ、別のワークツリーは対象外。Pythonテスト内の禁止例を示す文字列を実装ファイルと混同しない。配布HTML内のscriptやイベントハンドラの検査は既存の`tools.audit`が担当する。任意の言語によるJS実行可能性まで証明する一般解析器ではない。

3つのテストで、大文字の拡張子と入れ子の依存定義、生成物の除外、テスト内の文字列、シンボリックリンク、失敗時のCLI終了値を確認した。現在のソースのCLIも成功した。
