# Issue #71 停止した形の一覧

## 要件

全プリセットを、名前・初期値・静止したCSS描画で比較してから開く。カードの羅列ではなく、横罫線で区切る一覧行とする。小画面では描画と説明を上下に置く。

## 実装

`gallery.html`を生成・配布する。各図は96点、時計t=0、各プリセットのモデル・反復・位相・振幅を共有し、開くリンクの先では192点で開始する。図の名前と値は通常のHTMLにも記載する。

生成時にモデル選択CSSの既知prefixへ`data-static-model`条件を併記し、アプリと一覧で同じCSS数式を使う。式のコピーや座標画像にはしない。各図の`.gallery-example.lab`は、描画CSSの`.lab`より高い詳細度で`animation:none`と`--clock:0`を指定し、入力timelineや時計に初期値を上書きさせない。通常のアプリにはこのclassを付けない。

必要なCSS描画機能がない場合は図を隠して理由を表示し、名前・値・ページリンクを残す。特別な数学機能を要求するモデルを将来プリセットに選んだ場合も、モデルの機能検出用CSSへ静的モデル条件を同様に展開する。

## 検査

全80テスト成功。全7図のモデルとraw値、図ごと96点、入力要素がないこと、リンク先、生成対象・配布対象・監査の672点一致を検査した。selector展開がCSS数式を変えず、二重適用しないことも確認した。生成した13アプリファイルの静的監査に成功した。

実際の描画位置・小画面レイアウトは統合後のブラウザ検証へ残す。スクリーンリーダー・紙面印刷・実機性能の合格を主張しない。
