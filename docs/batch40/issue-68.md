# Issue #68 — 描画の近くで点数を切り替える

## 要件と変更

描画と時計の下に96・192・384点のページへの通常リンクを置く。現在の点数はリンクではなく`aria-current="page"`付きの強調として表示する。従来の仕組み説明内のリンクと同じ生成トークンを使い、表示の一致を保つ。

リンクによる別ページ移動であり、入力と時計の保持は保証しないとその場に説明する。集中表示でもナビゲーションを残し、自動比率の集中表示の高さは追加ナビゲーションの分を引く。比率を明示した場合はIssue #65の比率を優先する。印刷ではナビゲーションを隠す。

## 検査

`python3 -m tools.build`、`python3 -m tools.audit`、`python3 -m unittest discover -s tests -v`が成功（76 tests）。3つの密度ページとプリセットで同じリンク生成と参照監査を通過。実ブラウザでの移動、集中表示、小画面幅は統合検証に記録する。
