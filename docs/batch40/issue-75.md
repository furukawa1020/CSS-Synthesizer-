# Issue #75 — 生成結果の鮮度を変更せず検査する

`python3 -m tools.build --check`は一時ディレクトリに候補を生成し、通常と同じ監査を通してから、既存buildの名前と全バイトを照合する。不足、余分なファイルやディレクトリ、変更、シンボリックリンク、候補生成の失敗を非ゼロ終了で報告する。buildがなければ生成せず失敗する。候補は検査後に削除し、既存buildは変更しない。

4つのテストで成功時のバイト列とmtime保持、不足・変更・古いファイルの同時検出、CLI成功と失敗、ソースエラー時の保持、build不在時の非生成を確認した。通常の`python3 -m tools.build`は従来どおり候補を検証して配置する。このコマンドはソースのGitコミット状態や配信先の鮮度までは判定しない。
