# Issue #64 — 正規化座標を読む

## 要件

xとyの−1・0・+1を、原点から短辺44%の位置に置く。描画面の縦横比が変わっても目盛りの位置を座標計算と一致させる。

## 実装

.axesの子として5つの目盛りを置く。正のxは右、正のyは上。±1の位置は50%±44cqmin、文字は点と重ならない方向に6pxずらす。表示反転は.plotだけを反転するため軸は固定する。補助線「なし」では親のvisibilityとともに消え、「図中の説明」を外しても隠す。色は各配色・強制カラー・印刷に合わせる。

## 検証

Pythonビルド・生成HTML/CSS監査と既存76件のunittestを実行した。実ブラウザの360px幅・文字拡大・印刷分岐でのはみ出しと他の説明との重なりは統合検証で確認する範囲を記録する。実紙面や他ブラウザは未検証。
