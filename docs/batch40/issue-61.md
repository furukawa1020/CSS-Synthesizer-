# Issue #61 — 点の並びを色で読む

## 要件

単色を既定として、u=0〜1の点の順序を色で読める選択肢を加える。形の座標・時計は変えない。色だけに依存する操作は作らない。

## 実装

表示設定の通常のradioで切り替える。hsl()の色相を30〜210度へ変え、暗い描画面では明るく、紙配色では暗く描く。描画の下にu=0→1と「点の並び」の凡例を置く。強制カラー・印刷では単色を保ち凡例を隠す。色は時刻・速度・曲率を表さない。

## 検証

Pythonビルドと生成HTML/CSS監査を実行した。座標式・transform・時計宣言を変更していない。実ブラウザでの配色・操作・強制カラー、色覚別の識別は統合検証で確認する範囲を記録する。
