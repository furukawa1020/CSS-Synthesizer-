# Issue #69 可変件数のプリセット定義

## 要件

既存4件を保持し、1〜24件の停止プリセットを定義可能にする。`preset-*.html`の安全な小文字名、一意のファイル名・表示名、存在するモデル、初期目盛りに合う整数値を検査する。

## 実装

`tools.assets.asset_specs(source)`が対象ソースを呼び出し時に読み、生成・監査・配布・ZIP検査のファイル集合を決める。import時に固定するファイル一覧を撤去した。`build(root)`はそのrootの定義を候補監査へ渡すため、別fixtureのプリセット数にも追従する。

プリセット追加はHTMLへ保存する操作ではなく、ソース定義を変更して再生成する開発操作。

## 検査

Pythonテストで1件・2件の異なるfixture定義を同一プロセス内で再生成し、ファイル集合が追従することを確認。空・上限超過・不正パス・重複名・不正目盛り値を拒否する検査、既存4ページの選択・停止・初期目盛り・raw値の整合検査を実行した。全78テスト成功。

実ブラウザの初期スクロールは統合後の検証で確認する。実機・他ブラウザの合格を示さない。
