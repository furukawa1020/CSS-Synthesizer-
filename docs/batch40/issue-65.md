# Issue #65 — 描画領域の比率

## 要件と変更

「表示設定」に自動・正方形・横長16:9のラジオを追加する。自動は従来の画面幅別の高さを使う。明示比率は画面用CSSの`aspect-ratio`と自動高さで決め、集中表示でも選択比率を優先する。座標の44cqminは変更しない。

調整欄とscroll timelineには触れず、値や時計を変更する操作として案内しない。印刷は既定の140mm角を維持する。

## 検査

`python3 -m tools.build`と`python3 -m tools.audit`が成功。静的生成と参照を確認した。実ブラウザでの比率寸法・点座標・入力保持・小画面の観測は統合検証に記録する。実機タッチと紙への印刷は未検証。
