# Issue #76 — 配布ZIPのCI検査と20件の統合

## 要件

Issue #57〜#76の要件と実装を各日本語PRで追跡し、CI成功後にmainへ統合する。CIで生成したZIPは、同時に生成した外部manifestを指定して`tools.verify`で照合する。機能の実装、ブラウザでの観測、未検証の事項を区別して資料化する。

## 変更

CIの配布生成後に、次の検査を追加する。

```sh
python3 -m tools.verify dist/css-synthesizer-v0.1.zip --manifest dist/css-synthesizer-v0.1.manifest.json
```

生成・監査・配布・ZIP検査で現行のアセット定義を共有する。現在は8モデル、7プリセットと静的ギャラリー、11 HTML・2 CSSの13アプリファイル。README.txtとSHA256SUMSを含むZIPは15エントリーになる。

設定パネルの見出しと閉じるボタンをスクロール中も残し、ギャラリーの説明を小画面でも正しい表現に整えた。鮮度検査もCIへ追加する。

README、作業計画、要件、受け入れ状況を更新し、今回の一覧と[統合検証](validation.md)へ結び付ける。以前の20件の記録は当時の証跡として保持する。
