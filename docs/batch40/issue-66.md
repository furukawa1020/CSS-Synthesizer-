# Issue #66 — 自動時計の周期内の位置

## 要件と変更

描画の下に1周24秒の時計の位置を整数度で表示する。CSSの`--clock`ラジアン値を同じ値から度へ換算して四捨五入し、0〜360°をCSS counterで示す。周期の末尾では丸めにより360°になり、次周期で0°になる。入力の位相φとは別の値と説明する。

停止・端末に従う・再生の既存時計を参照するだけで、時計の駆動方法や周期を変えない。印刷でも時計の度と元のミリラジアンを入力位相と区別する。CSS生成テキストの読み上げ更新通知は保証しない。

## 検査

`python3 -m tools.build`と`python3 -m tools.audit`が成功。ブラウザでの停止時保持・再生時進行・数値表示は統合検証に記録する。実スクリーンリーダーの更新通知は未検証。
