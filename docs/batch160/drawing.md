# 新しい描画と観察

u=i/(N−1)、θ=2πu、入力の位相をφ、振幅をA、時計をtとする。入力kの意味はモデルごとに異なる。

| モデル | 座標 | k・φ・tの意味 |
| --- | --- | --- |
| 楕円 | X=A cosθ、Y=A sinθ/kをφ+tで回転 | kは横/縦の半径比で、反復数ではない。非整数でも閉じる |
| アステロイド | X=A cos(kθ+φ)³、Y=A sin(kθ+φ)³をtで回転 | kは辿る回数、φは辿り始める位置。尖点では矢印を隠す |
| 余弦半径 | r=A(1+cos(kθ+φ))/2、(x,y)=r(cos(θ+t),sin(θ+t)) | k=1、φ=0でカージオイド。r=0の尖点では矢印を隠す |
| 外転曲線 | c=1+1/k、q=(k+1)θ+φ、X=A(c cosθ−0.35 cosq)/(c+0.35)、Y=A(c sinθ−0.35 sinq)/(c+0.35)をtで回転 | R=1、転がる円半径1/k、描画点距離0.35のエピトロコイド。整数kで閉じる |

後3モデルの非整数kは終端が開く場合がある。楕円以外のkを半径比や反復の共通意味として読み替えない。接線はu方向の解析微分で、時間方向の速度ではない。既存の座標加工中は接線形状を丸点へ戻す。

## 点の観察

- 十字は点の塗りだけをclip-pathで切り抜く。点の中心・座標・並びは変えない。
- 距離色：加工後のr=hypot(x,y)を0〜1に制限し、色相30〜210度へ対応させる。r>=1は飽和する。
- 角度色：atan2(y,x)を色相へ対応。+x=0度、+y=90度。原点は角度が未定義なので0度の色に固定する。
- 距離の濃淡：固定不透明度へ0.25+0.75×clamp(0,r,1)を掛ける。範囲・間隔による非表示はそのまま。

色と濃淡は加工後・表示変換前の座標を使う。表示の反転・回転・倍率で色を再計算しない。色・濃淡は印刷と強制カラーでは解除する。対応構文がない場合は選択肢を隠す。構文診断は色相への関数適用も別項目として検出し、実動作の保証と区別する。

## 座標の基準

原点の印と半径1の円は、グリッドとは別に任意表示できる。円の中心は領域中央、半径は短辺の44%。境界線の中心がその半径になるよう幅を調整した。座標軸と同じ固定目盛りで、プロットの表示倍率・反転・回転では動かさない。極グリッドは8/12/24分割、直交の格子間隔とは独立。表示倍率125/150%は等方拡大で、枠外を切り抜く。

## 保存時計

JSONへclock_period_seconds=6/12/24/48/96、clock_direction=forward/reverseを指定できる。省略時は24とforward。時計は停止から始まり、既存のネイティブな周期・方向のラジオへ初期選択を反映する。

CSSは登録した--clock-progressを0〜2πでアニメーションし、--clockをmod(保存位置+進行量,2π)から求める。逆方向の初期進行量2πも保存位置と等価になり、そこから時計が減少する。0と2πは同じ周期内位置として表示する。周期・方向を途中で切り替えると位置が移り得る。新しいライブの停止・再開・切替は未検証である。

```sh
mkdir -p tmp
python3 -m tools.scene qa/scene-observation-example.json --output tmp/observation-scene
python3 -m tools.serve --directory tmp/observation-scene --port 0
```

ブラウザー内の変更を自動保存する機能ではない。詳しくは[保存シーンの手順](../batch140/scenes.md)。
