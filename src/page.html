入力・数理コアの検証 / Issue #1

これは最終UIではなく、操作と数式の対応を確かめるための検証画面です。

このブラウザでは連続入力に必要なCSS機能が不足しています。入力帯は表示せず、描画機能が使える場合は基準値の図形を表示します。現行Chrome / Edgeで検証してください。

このブラウザではCSSによる座標描画を利用できません。数式と入力の説明を参照できます。

数式・入力の意味・検証上の制限

x = A sin(kθ + φ + t)
y = A sin(2θ + t)

x = 2u − 1
y = A sin(2πku + φ + t)

uは点の位置を0〜1で表した値、θ=2πu。座標の倍率は横・縦とも描画領域の短辺の44%です。kは時間の速度ではありません。整数のkではリサージュの端点が一致し、非整数では開いた形になる場合があります。

表示と描画は同じ丸め済みの有効値を使います。kは小数2桁、位相は1°、振幅は1%単位です。帯の目盛り間も連続的に調整できます。

HTMLのラジオボタンとCSSのスクロールタイムラインを使っています。数値はCSS生成テキストであり、読み上げでの値の更新通知は未検証です。実機タッチ・別ブラウザ・性能の評価はIssue #3で行います。初期停止位置はscroll-initial-targetで指定し、履歴復元時はブラウザが復元した位置から値が決まります。

描画点数：@@DENSITIES@@。点数の比較用ページです。最適な点数を決定したものではありません。

実行時のコードはHTML / CSSのみ。開発用ツールはPython標準ライブラリのみです。
