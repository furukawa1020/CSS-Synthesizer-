# 比較表示と時計の観測

Chrome155 / Linux UAで採取した22ケース・2,304点。座標はDOMの中心、接線は疑似要素のローカル角度（親plotの反転回転と、範囲の親opacityによるmask前）を読む。JSONは独立式への入力で、期待値から作成した観測ではない。

index.jsonは座標22件、tangents-index.jsonは接線22件の明示一覧。checks.jsonは時計・reset・表示とUA、gallery.jsonは絞り込み、layout.jsonはiframe幅。results.jsonはPython独立照合の集計。CSS分岐fixtureは実OS/印刷の合格ではない。

[条件と制限](../../../docs/batch80/validation.md)。資料は配布ZIPに含めない。
